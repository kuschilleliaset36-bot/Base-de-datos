Aprende a gestionar y consultar bases de datos relacionales

01

HISTORIA Y ORIGEN DE SQL

SQL (Structured Query Language o Lenguaje de Consulta Estructurado) nació a principios de los años 70 en los laboratorios de investigación de IBM en San José, California.

Se basó en el modelo relacional propuesto por Edgar F. Codd en 1970. Basándose en este modelo, los investigadores Donald D. Chamberlin y Raymond F. Boyce desarrollaron el lenguaje original llamado SEQUEL (Structured English Query Language) para manipular y recuperar datos almacenados en el sistema experimental de IBM llamado System R.

Debido a un problema de marcas registradas con una empresa de aviación, el nombre se acortó a SQL.

En 1986, el American National Standards Institute (ANSI) estandarizó el lenguaje SQL, seguido por la ISO en 1987. Desde entonces, SQL se ha convertido en el estándar universal para interactuar con Sistemas de Gestión de Bases de Datos Relacionales (RDBMS) como MySQL, PostgreSQL, Oracle, SQL Server y SQLite.

02

CONCEPTOS CLAVE DE UNA BASE DE DATOS

Una base de datos relacional organiza la información en estructuras llamadas Tablas, las cuales se componen de Campos y Registros. Puedes imaginarlo como una planilla de cálculo interactiva.

1. Tablas

Es una colección de datos organizados en filas y columnas. Por ejemplo, una tabla llamada usuarios o productos.

2. Campos (Columnas)

Definen el tipo de información que guardará la tabla. Cada campo tiene un nombre único y un tipo de dato especificado (por ejemplo: texto, número entero, fecha).

3. Registros (Filas)

Es cada una de las entradas de datos individuales almacenadas en la tabla. Cada fila contiene los valores correspondientes a cada columna.

Ejemplo práctico: Tabla "usuarios"

id (Campo) nombre (Campo) email (Campo) edad (Campo)
1 Ana Gómez ana@mail.com 28
2 Carlos Pérez carlos@mail.com 34

Nota: La tabla tiene 4 campos (columnas) y 2 registros (filas).

03

EJEMPLOS DE CONSULTAS SQL EXPLICADAS

Las consultas son las sentencias que le enviamos a la base de datos para leer o modificar información.

1. Seleccionar datos — SELECT

Sirve para consultar registros. Especificas qué columnas quieres ver y de qué tabla extraerte los datos.

SELECT id, nombre, email
FROM usuarios;

2. Filtrar información — WHERE

Filtra los resultados devolviendo únicamente los registros que cumplen una condición lógica específica.

SELECT *
FROM productos
WHERE precio > 10000;

3. Ordenar resultados — ORDER BY

Ordena los registros devueltos de forma ascendente (ASC) o descendente (DESC) según una columna.

SELECT modelo, precio
FROM autos
ORDER BY precio DESC;

4. Agrupar datos — GROUP BY

Agrupa filas que tienen los mismos valores en columnas especificadas. Se suele combinar con funciones como COUNT() o SUM().

SELECT marca, COUNT(*) AS total
FROM autos
GROUP BY marca;

5. Combinar tablas — INNER JOIN

Une filas de dos o más tablas basándose en una columna común que existe en ambas (clave foránea).

SELECT usuarios.nombre, pedidos.producto
FROM usuarios
INNER JOIN pedidos ON usuarios.id = pedidos.usuario_id;

6. Insertar nuevos datos — INSERT INTO

Agrega un nuevo registro o fila dentro de una tabla especificando sus campos y valores correspondientes.

INSERT INTO usuarios (nombre, email)
VALUES ('Juan', 'juan@email.com');

7. Modificar datos — UPDATE

Actualiza valores de campos existentes. ¡Atención! Siempre utiliza WHERE para no modificar toda la tabla.

UPDATE usuarios
SET email = 'nuevo@email.com'
WHERE id = 1;

8. Eliminar datos — DELETE

Elimina uno o varios registros específicos según la condición del filtro WHERE.

DELETE FROM usuarios
WHERE id = 1;

GUÍA DE INSTALACIÓN: XAMPP Y MYSQL WORKBENCH

Para trabajar en tu propia computadora necesitas dos cosas: un **Servidor de Base de Datos** (donde se guardan los datos) y una **Interfaz Gráfica** (para escribir comandos de forma cómoda).

Paso 1: Instalar XAMPP (Servidor Local)

  1. Ingresa a apachefriends.org y descarga el instalador de XAMPP para tu sistema operativo.
  2. Ejecuta el instalador dejando las opciones por defecto y completa la instalación.
  3. Abre el XAMPP Control Panel.
  4. Haz clic en el botón Start junto al módulo MySQL. Al ponerse en verde, el servidor estará activo en tu máquina local.

Paso 2: Instalar y Configurar MySQL Workbench

  1. Ingresa a dev.mysql.com/downloads/workbench/ y descarga la versión gratuita.
  2. Sigue las instrucciones del asistente de instalación.
  3. Abre MySQL Workbench. En la pantalla principal verás un apartado llamado MySQL Connections.
  4. Haz clic en el ícono de suma (+) para agregar una conexión:
    • Connection Name: Localhost XAMPP
    • Hostname: 127.0.0.1
    • Port: 3306
    • Username: root
    • Password: (Déjalo vacío por defecto si usas XAMPP)
  5. Haz clic en Test Connection y luego en OK. ¡Ya estás listo para crear tu primera base de datos!
